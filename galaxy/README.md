## Запуск

Разверните Galaxy, выполнив:

```bash
sh run.sh
```

Откройте веб-интерфейс: [http://localhost:8080](http://localhost:8080)
Создайте аккаунт и авторизуйтесь.

---

## Выполнение воркфлоу

1. Перейдите на вкладку **Workflows**.
2. Нажмите кнопку **Create**.
3. В разделе **Tools** найдите набор **Seismic**.
4. Создайте воркфлоу, состоящий из двух инструментов **Task 1** и **Taks 2**
5. Создайте новую историю в разделе **History**, добавьте исохдный файл с расширением .sgy.
6. Запустите созданный воркфлоу, передав в качестве исходных данных добавленный .sgy файл
